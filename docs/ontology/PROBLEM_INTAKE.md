# 기출 문항 입력 규격 — 조교용 안내서

> 이 문서는 조교에게 그대로 전달하는 안내서입니다. (2026-08-12 v2 — 문제은행 구조로 확장)
>
> **기본 경로 (경로 A):** 원장이 `기출PDF\` 에 PDF 저장 → **AI(Claude)가 직접 LaTeX 전사 +
> 자기검증(형식 검사 + 문항을 실제로 풀어 정답 대조)** → `기출원고\검수대기\` 에 원고 저장 →
> **조교는 검수만** (아래 3장 — 조교 PC 브라우저의 원격 검수 페이지) → 통과본을
> `기출원고\` 로 이동 → 문제은행 등록.
> **백업 경로 (경로 B):** 조교가 Gemini 로 변환(4장 프롬프트) → 검수 → `기출원고\` 저장.
>
> 문제은행은 온톨로지 검증(태깅·실행 검증)과 학원 시험지·교재 제작에 함께 쓰입니다.
> 저작권 구분(평가원/교육청/학교내신/출판사)은 출처에서 자동 기록되며, **출판사 문항은
> 내부 참고·변형 출제용으로만** 씁니다.

## 1. 파일 하나 = 시험 하나 (또는 교재의 단원 하나)

일반 텍스트 파일(`.md` 또는 `.txt`)로 저장합니다. **인코딩은 반드시 UTF-8**
(메모장에서 "다른 이름으로 저장" 시 인코딩 칸에서 UTF-8 선택).

저장 위치: `바탕화면\임페리얼 수학 온톨로지\기출원고\`

### ⚠️ 공통과목과 선택과목은 파일을 나눕니다

수능·모평·학평은 1~22번(공통)과 23~30번(선택: 미적·확통·기하)을 **별도 파일**로
저장합니다. 이유: 문항 번호가 과목 안에서만 의미가 있고(`…-공통-22`, `…-미적-30`),
공통 문항은 세 선택과목 응시자가 모두 풀므로 한 번만 입력하면 됩니다.
나중에 다른 선택과목을 추가할 때 공통을 다시 만들 필요가 없습니다.

파일명 규칙:

| 소스 | 파일명 예 |
|---|---|
| 수능 | `2024_수능_공통.md` (1~22번) / `2024_수능_미적.md` (23~30번) |
| 모평 (평가원 6·9월) | `2024_06모평_공통.md` / `2023_09모평_확통.md` |
| 학평 (교육청 3·5·7·10월) | `2026_07학평_공통.md` / `2026_07학평_미적.md` |
| 내신 | `2024_충암고_2학년_1학기중간_공통수학1.md` |
| 문제집 | `쎈_공통수학1_04단원.md` |

## 2. 파일 형식

파일 맨 위에 시험 정보를 적고, 문항마다 `=== 문항 <번호>` 로 시작하는 블록을 씁니다.

```
[출처] 수능
[연도] 2024
[과목] 공통

=== 문항 22
[배점] 4
[정답] 195
[정답률] 5
[유형] 단답
[본문]
최고차항의 계수가 $1$인 삼차함수 $f(x)$가 모든 실수 $x$에 대하여 ... 를
만족시킬 때, $f(10)$의 값을 구하시오.

=== 문항 10
[배점] 4
[정답] 3
[유형] 5지선다
[그림]
곡선 $y=x^2-4x+3$ 과 직선 $y=x-1$ 이 두 점에서 만나고, 두 그래프로
둘러싸인 영역이 빗금으로 표시되어 있다.
[본문]
그림과 같이 곡선 ... 넓이는? [4점]
[보기]
① $\dfrac{9}{2}$ ② $5$ ③ $\dfrac{11}{2}$ ④ $6$ ⑤ $\dfrac{13}{2}$
```

머리 정보 키 (해당하는 것만):

| 키 | 값 | 소스 |
|---|---|---|
| `[출처]` | 수능 · 06모평 · 09모평 · 03학평 · 05학평 · 07학평 · 10학평 · 내신 · 문제집 | 전부 |
| `[연도]` | 2024 | 수능·모평·내신 |
| `[과목]` | 공통 · 확통 · 미적 · 기하 (수능·모평) / 공통수학1 등 실제 과목명 (내신) | 전부 |
| `[학교]` `[학년]` `[시험]` | 충암고 / 2 / 1학기중간 | 내신만 |
| `[교재]` | 쎈 공통수학1 | 문제집만 |
| `[원본]` | `2026_07학평_미적분.pdf` | 선택 — 원본 PDF 파일명 (재활용·검수 회귀용) |
| `[전사]` | claude 또는 gemini | 선택 — 전사 주체 기록 |

문항 블록 키:

| 키 | 필수 | 설명 |
|---|---|---|
| `[배점]` | 권장 | 숫자 |
| `[정답]` | **필수** | 단답은 값, 5지선다는 번호(①~⑤ 또는 1~5) |
| `[정답률]` | 있으면 | **% 단위 정수** (예: 5 = 5%). 수능·모평의 공개 추정치 |
| `[유형]` | 필수 | 단답 · 5지선다 · 서술형 |
| `[그림]` | 그림 문항만 | 그림이 담은 수학적 정보를 글로 완전히 서술 (아래 3-③ 참조) |
| `[그림자산]` | 그림 문항만 (AI 가 자동 기입) | 원본 페이지 PNG 파일명 — 데이터 레포 `tags/assets/` 참조. 시험지 재제작용 원본 |
| `[본문]` | **필수** | 문항 전문. 수식은 `$...$` |
| `[보기]` | 5지선다만 | ①~⑤ 순서대로 |

### 표기 규칙 (1차 검수에서 실증된 함정 — 전사 시 반드시 지킬 것)

- **수식 구분자는 `$...$` 하나뿐. `$$...$$` 절대 금지** — `$$` 는 `$` 짝맞춤 패리티를
  뒤집어 이후 수식 전체를 어긋나게 한다 (한글이 수식 글꼴로 들어가고 `\sum` 이 날것으로
  노출됨). 렌더러가 관용 처리하며 경고를 내지만, 원고 자체를 `$` 로 쓴다.
- **시험지 테두리 박스**(조건 (가)(나), 시행 설명, `<보기>` ㄱㄴㄷ 상자)는 박스 안
  줄마다 맨 앞에 `| ` 를 붙인다 (박스 안 빈 줄은 `|` 단독). 연속한 `| ` 줄이 박스
  하나로 조판된다. `<보기>` 단독 줄이 박스 바로 앞에 오면 박스 윗변의 <보 기> 표제가
  된다. 대괄호 `[...]`(키로 오인됨), 문자 그림 `┌─┐`, 가로줄 `───` 로 박스를 흉내
  내지 않는다.
- **그림이 없으면 `[그림]` 키를 아예 쓰지 않는다** — "그림 없음" 같은 자리표시자를 넣으면
  그림 문항으로 오인되어 자산 추출·중점 검수 대상이 된다.
- **표(표준정규분포표 등)는 산문이 아니라 LaTeX 격자로** —
  `$\begin{array}{|c|c|} \hline z & \mathrm{P}(0 \le Z \le z) \\ \hline \dots \end{array}$`
- **원문 강조(밑줄·굵음)는 `**...**` 로 전사한다** — 예: 옳지 **않은** 것은?. 검수 페이지가
  밑줄로 렌더한다. **빈칸 네모 상자**((가)·㉠ 등 채울 자리)는 `$\boxed{\text{(가)}}$` 로.
- **배점 표기 `[4점]` 은 원문 그대로 전사한다** (검수가 원본 대조이므로). 은행 등록 시
  변환기가 자동 제거한다 — 배점은 `points` 필드로 저장되고, 시험지 재제작 때 조판
  단계에서 다시 붙인다.

## 3. 조교 검수 — 원격 검수 페이지 (파일당 5분)

검수는 원장 PC 가 아니라 **조교 본인 컴퓨터의 브라우저**에서 한다 (보안 자료가 있는
원장 PC 에 조교를 앉히지 않는다). AI 가 검수대기 원고를 **수식이 렌더된 웹페이지**
(비공개 링크)로 발행하면, 원장이 페이지의 공유 메뉴로 링크를 열어 조교에게 전달한다.
StackEdit 에 수동으로 붙여 넣는 단계는 필요 없다 — 페이지에 수식 렌더 + 그림 문항의
원본 시험지 페이지가 나란히 들어 있다.

(생성 절차 — AI 용: 데이터 레포에서 `node scripts/build-review-page.js` 실행 →
`기출원고\검수대기\_검수페이지.html` 을 Artifact 로 발행 → 링크를 원장에게 전달)

**조교 사용법:**
1. 문항마다 **통과** 또는 **수정 필요** 버튼을 누르고, 수정 필요면 메모를 남긴다
   (예: "보기 ③ 분수 분자·분모 바뀜"). 진행 상황은 브라우저에 자동 저장된다.
2. 검수 포인트 (우선순위순):
   - **그림 서술 자가 테스트** — "그림 검수 중점" 표시 문항: 그림 서술만 읽고 그림 없이
     문제를 풀 수 있는가? 옆의 원본 페이지와 대조하고, 부족하면 보강할 수치(좌표·교점·
     기울기 등)를 메모에 적는다. 자기검증이 가장 못 잡는 영역이라 검수의 핵심이다.
   - **수식 확인** — 깨져 보이는 수식·빨간 수식 = LaTeX 오타 → 수정 필요.
     (수식·정답의 수학적 정합성은 AI 가 전 문항을 실제로 풀어 정답표와 대조를 마친
     상태이므로 훑어보기면 충분하다.)
   - **보기 중복** — ①~⑤ 에 같은 값이 두 개면 십중팔구 전사 오류.
   - **문항 누락** — 각 시험 섹션의 문항 수가 원본과 일치하는가.
3. 끝나면 우측 상단 **검수 결과 복사** → 나온 텍스트를 원장에게 카톡·메일로 보낸다.
   수정 반영은 원장·AI 가 하고(변환기 `--update`), 고친 뒤 페이지를 같은 링크로
   재발행하여 해당 문항만 재검수한다.

⚠️ 검수 페이지 링크는 내부용이다 — 외부 게시·재공유 금지.
(경로 B 로 조교가 직접 파일을 만들 때는 종전대로 https://stackedit.io 에 붙여 넣어
수식 렌더를 확인한다.)

## 4. Gemini 에게 줄 프롬프트 (복사해서 사용)

PDF(또는 페이지 캡처 이미지)와 함께 아래를 붙여 넣습니다:

```
너는 수학 시험지를 텍스트로 옮기는 전사자다. 첨부한 시험지의 모든 문항을
아래 형식으로 빠짐없이 옮겨라.

=== 문항 <번호>
[배점] <숫자>
[정답] <모르면 이 줄 생략>
[유형] <단답 또는 5지선다>
[그림] <그림이 있는 문항만. 그림이 담은 수학적 정보(곡선의 식, 교점, 좌표,
       각, 길이 등)를 글만 읽고 문제를 풀 수 있을 만큼 완전히 서술>
[본문]
<문항 전문. 수식은 반드시 $...$ 안에 LaTeX 로: 분수 \dfrac{a}{b}, 제곱근
\sqrt{}, 극한 \lim_{x \to 0}, 적분 \int_0^1, 시그마 \sum_{k=1}^{n}.
문장·조건·[배점] 표기까지 원문 그대로. 절대 풀거나 요약하지 말 것>
[보기]
<5지선다만: ① ~ ⑤ 순서대로 한 줄에>

규칙: 문항을 하나도 빠뜨리지 마라. 원문에 없는 내용을 추가하지 마라.
확신이 없는 글자·수식은 <?> 로 표시하라.
수식 구분자는 $...$ 만 쓰고 $$...$$ 는 금지.
조건·시행·<보기>가 테두리 박스 안에 있으면 그 줄들 맨 앞에 "| " 를 붙여라.
그림이 없는 문항에는 [그림] 줄을 만들지 마라.
```

정답표는 별도 대화로 옮기거나 조교가 직접 `[정답]` 줄을 채웁니다.

## 0. 원장용 — PDF 올리는 규칙 (경로 A 입력)

`기출PDF\` 폴더에 **원본 그대로, 자르지 말고** 올린다. 공통+선택이 한 파일에 같이 있어도
됨 — AI 가 공통은 한 파일에서만 전사하고 장부가 중복을 막는다.

| 소스 | 파일명 |
|---|---|
| 학평·모평·수능 | `2026_07학평_미적분.pdf` / `_확통.pdf` / `_기하.pdf` (선택과목별 원본 3개 전부) |
| 해설 (권장) | `2026_07학평_해설.pdf` — EBS 해설 PDF. 정답표 포함 + [출제의도]로 태깅 교차 검증 + [다른 풀이]로 alternative_to·faster_than 발굴. 과목별 분리본이면 `_해설_확통.pdf` 식 접미사로 전부 |
| 고2 학평 | `2026_고2_07학평_수학.pdf` + `2026_고2_07학평_해설.pdf` — 고2는 선택과목 없는 단일 시험지. 원고 헤더에 `[학년] 2`, `[과목] 수학` (문항 id 가 고3과 충돌하지 않게 `-고2-` 삽입됨. 고3은 학년 표기 생략) |
| 정답만 | `2026_07학평_정답.png` — 해설 PDF 를 못 구한 시험만 |
| 내신 | `2024_충암고_2학년_1학기중간_공통수학1.pdf` + `..._답안.pdf` |
| 문제집 | `쎈_공통수학1_04단원.pdf` (책 전체보다 단원 단위 권장) |

정답 소재가 가장 중요하다 — 풀이 대조의 기준. **해설 PDF 가 최선** (정답+출제의도+다른풀이).
⚠️ 해설 텍스트는 저작권상 문제은행에 저장하지 않는다 — 내부 검증(정답 대조·태깅 교차
확인·관계 발굴)에만 쓰고, 은행에는 사실 정보(정답·정답률)와 자체 서술만 넣는다.
화질은 배포 원본 PDF 최선, 스캔본은 300dpi 이상. 올린 뒤 "PDF 넣었어" 한마디면 된다.

## (참고) AI 전사 절차 (경로 A 의 내부 규약) — 조교는 몰라도 됨

통째 전사는 중후반 문항의 품질이 떨어진다 (Gemini 통째 전사에서 정답 6건 오기 실증).
AI 는 반드시 다음 절차로 전사한다:

1. **페이지 단위 분할** — PDF 를 1~2페이지(문항 2~4개)씩 잘라 페이지당 에이전트 1개로
   병렬 전사 (Read 의 pages 파라미터). 통째 읽기 금지.
2. **정답표 별도 전사** — 본문과 독립적으로 전사 후 기계 병합 (같은 오류 공유 방지).
3. **풀이·정답 대조** — 전사 직후 전 문항을 실제로 풀어 정답표와 대조. 불일치 문항만
   해당 페이지 재정밀 판독. 수학적 의미를 바꾸는 전사 오류(부호·지수·계수)는 여기서 걸린다.
4. 킬러 문항(배점 4·저정답률·수식 밀집)은 필요시 **이중 전사 대조** (독립 2회 → diff →
   불일치만 재판독).
5. 형식 검사(변환기 dry-run) 통과본만 `기출원고\검수대기\` 에 저장하고, 검수 요약
   (자기검증 결과·의심 문항 플래그)을 함께 남긴다.
